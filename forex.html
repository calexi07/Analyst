Import & export

📥 Import fundamental analysis

Paste the Daily Observer import block from the bottom of your Fundamental Bias Engine report. Next you choose the week, the pairs and the sections.

📤 Export price action for AI review

Only price action: the daily close % for each pair you logged, the weekly total and the realized currency strength. No thesis, notes or trades — the AI already has its own report.

Import from Google Sheets

In Google Sheets: File → Download → CSV, from the pair's tab. Rows are imported into the currently selected pair (). Columns are matched by header name (Date, Trade, Session, Long/Short, W/L, USD News, EUR News, Daily Observations etc.). The daily close % is extracted automatically from „Price closed ±x%”.
